# DOAS™ Metrics Specification

## Purpose

Defines how scoring metrics are interpreted and applied.

---

## Metric Types

### Quantitative Metrics

- Score (0–10)
- Weighted score (0–100)

---

### Qualitative Metrics

- Justification statements
- Observations
- Improvement notes

---

## Evaluation Layers

1. Input Analysis  
2. Output Review  
3. Constraint Matching  
4. Logical Validation  
5. Final Scoring  

---

## Reporting Structure

Each DOAS™ report must include:

- Summary
- Dimension breakdown
- Weighted score
- Classification
- Recommendations

---

## Standardization

All reports must follow consistent formatting for:

- Machine readability
- Human interpretation
- API compatibility
