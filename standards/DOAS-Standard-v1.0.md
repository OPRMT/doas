# DOAS™ Standard v1.0

## 1. Scope

This document defines the official standard for the DOAS™ (Dynamic Output Assessment System), including evaluation structure, scoring rules, and classification methodology.

This standard applies to:

- AI-generated outputs
- Prompt engineering workflows
- Automated and manual evaluations
- Certification systems under OPRMT™

---

## 2. Definitions

DOAS™: A structured scoring system used to evaluate AI output quality.

Evaluation Unit: A prompt-output pair subject to scoring.

Dimension: A measurable category used in scoring.

Weighted Score: Final computed score based on dimension weights.

---

## 3. Evaluation Requirements

All DOAS™ evaluations MUST:

- Include all 8 scoring dimensions
- Use a 0–10 scoring range per dimension
- Apply official weighting model
- Produce a final weighted score
- Include justification for each score

---

## 4. Scoring Integrity Rules

Evaluations MUST be:

- Objective
- Repeatable
- Justified
- Consistent across evaluators

---

## 5. Output Requirements

Each evaluation MUST return:

- Dimension scores
- Weighted score (0–100)
- Classification level
- Improvement recommendations

---

## 6. Classification Enforcement

Scores MUST map to the official rating scale:

- 90–100: Elite
- 80–89: Professional
- 70–79: Functional
- 60–69: Weak
- <60: Failure

---

## 7. Compliance

All DOAS™ implementations MUST adhere to:

- Ethical AI usage
- Non-harmful output evaluation
- Transparency in scoring logic
