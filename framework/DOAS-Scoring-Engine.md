# DOAS™ Scoring Engine

## Overview

The DOAS™ scoring engine processes prompt-output pairs into structured evaluations.

---

## Input Layer

- Prompt
- Output
- Profile

---

## Processing Layer

1. Dimension evaluation
2. Score assignment
3. Weight application
4. Final calculation

---

## Output Layer

- Score breakdown
- Final score
- Classification
- Recommendations

---

## Design Principle

The engine must be:

- Deterministic in structure
- Flexible in interpretation
- Consistent in scoring
