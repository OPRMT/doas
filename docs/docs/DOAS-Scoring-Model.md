# DOAS™ Scoring Model

## Overview

The DOAS™ scoring model evaluates AI outputs using a weighted multi-dimensional framework.

---

## Scoring Dimensions

| Code | Dimension | Description |
|------|----------|------------|
| OA | Objective Alignment | Accuracy of meeting intent |
| PP | Parameter Precision | Clarity and constraint adherence |
| OA2 | Output Accuracy | Correctness and completeness |
| MI | Method Integrity | Logical process validity |
| TU | Tool Utilization | Effective use of tools |
| CR | Consistency | Repeatability of results |
| EF | Efficiency | Resource and time optimization |
| CS | Compliance | Safety and ethical adherence |

---

## Scoring Range

Each dimension is scored:

0 → Complete failure  
10 → Perfect execution  

---

## Weighting Formula

Final Score Calculation:

(OA × 0.20) +
(PP × 0.15) +
(OA2 × 0.20) +
(MI × 0.15) +
(TU × 0.10) +
(CR × 0.10) +
(EF × 0.05) +
(CS × 0.05)

---

## Output

The system produces:

- Weighted score (0–100)
- Classification tier
- Performance insights
